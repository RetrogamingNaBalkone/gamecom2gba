# Правила проекта

- В Git храним собственный код, описания форматов, тесты и нарисованную для порта графику. Оригиналы пользователя находятся в `originals/`. Дампы BIOS, ROM, декомпиляцию, извлечённые картинки, звук, игровые снимки и готовые образы оставляем вне Git. Исключение — скриншоты для README в `docs/images/`.
- Репозиторий локальный. Сборочное окружение и проекты Ghidra помещаем в `build/`, готовые сборки — в `dist/`. Каждый скрипт удаляет созданные им временные файлы, включая случай ошибки.
- Используем общие установки Zig, mGBA и Ghidra. Дополнительные инструменты устанавливаем для пользователя или системы, чтобы их могли использовать следующие проекты.
- Каждый порт нативный. Пользователь подаёт собственный ROM, при необходимости — BIOS. До извлечения ресурсов сверяем содержимое с белым списком. Общие инструменты и графические преобразования должны подходить для следующих игр.
- Исследуем код в Ghidra. Устройство game.com и палитру сверяем с MAME. Для графики используем возможности GBA, отдельные слои и спрайты. Покадровое копирование фреймбуфера game.com исключено. Частота отрисовки независима от игрового времени.
- Исходные 200×160 пикселей располагаем по центру экрана 240×160. По бокам — полосы цвета корпуса, слева вертикальная game.com, справа tiger.
- Кнопки назначаем по игровым действиям. Для действия, доступного только касанием, описываем варианты и ждём решения пользователя. Для секрета выдачи предметов Duke согласованы два отдельных нажатия Select после исходной комбинации на паузе.
